% THE FOUR PATTERNS USED, and why each was chosen rather than a blanket substitution:
%
% 1. PARENTHESES, when the aside contains its own commas, so that commas alone would blur where
%    the aside starts and ends. E.g. "between locomotion modes ---quadrupedal walking, differential
%    rolling, and omnidirectional motion--- when facing" -> "(quadrupedal walking, differential
%    rolling, and omnidirectional motion)". Also used when the aside is a full clause
%    ("reactive navigation without spatial memory can fail ...") or when it sits between two
%    members of a parallel construction, where commas would break the parallel: "prone to
%    mechanical compliance (a deviation between the commanded and achieved joint angle) and to
%    abrupt-command-induced instability".
%
% 2. COMMAS, for a short appositive with no internal punctuation: "at the instant of morphological
%    switching itself, the moment all four feet share ground contact for maximum support, the
%    Normalized Stability Margin reached ...". Also for trailing appositions that close a sentence:
%    "..., a distinction relevant to how this suite's robustness should be characterized".
%
% 3. COLON, when the dash introduced the explanation or consequence of what precedes it, which is
%    what a colon is for: "well-matched to the task: one stimulus is active at a time";
%    "already combines all three simultaneously: no configuration isolates a single sensor's
%    contribution"; "(not a success-rate metric: every mission in this dataset eventually
%    succeeds".
%
% 4. SEMICOLON, when the dash joined two statements that each stand alone: "rarely met in practice
%    across these trials; this is a limitation of the metric's present instrumentation";
%    "no dispersion to display; see the accompanying prose for that result".
%

%    comma-delimited groups before the verb; folding the model's name into the noun phrase keeps
%    one.
%  - results.tex: two lists whose items already contained commas ("approach (a, appetitive),
%    evasion (b, obstacle), and escape (c, aversive)" and the three locomotion modes) were switched
