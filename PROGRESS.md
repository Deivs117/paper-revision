README.md §6. Status values: `pending` → `drafted` → `applied` → `synced-to-overleaf`.

`results.tex`, `conclusions.tex` — see `OUTLINE.md` for details).

exist yet, it points at `experiments/<ID>-<slug>/` — see README.md §9 / `experiments/README.md` for that
workflow (generation scripts → `output/` → `scripts/promote_figure.sh` → `assets/`).

both directly from this table, so keep them current when reassigning or picking up a row.
